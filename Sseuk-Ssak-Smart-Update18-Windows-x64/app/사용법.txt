쓱-싹 v0.7.13 · Windows x64 · Portable

실행
새 폴더에 ZIP을 모두 풀고 쓱-싹.exe를 실행하세요. 쓱-싹.exe와 app 폴더를 함께 두세요.
Python 실행 환경은 포함되어 있습니다. Google Chrome 또는 Microsoft Edge가 있어야 합니다. 크롬 다운로드 정리는 Chrome에서만 됩니다.

크롬 다운로드 정리 (이번 버전에서 도우미 재등록 필요)
1. 앱의 크롬 다운로드 → 도우미 등록하기를 누르세요.
2. chrome://extensions에서 기존 쓱-싹 도우미를 제거하고, 개발자 모드를 켜고 새 ‘크롬 다운로드 연결 도우미’ 폴더를 압축해제된 확장 프로그램으로 등록하세요.
3. 앱에서 다운로드 파일 확인을 누르면 사용하는 Chrome 프로필의 다운로드 완료 목록을 읽습니다.
4. 실제 파일이 있는 항목을 같은 폴더·확장자·기본 이름으로 묶습니다. abc.html, abc(1).html, abc(2).html이 한 묶음입니다.
5. 남길 기준: 실제 파일 수정 날짜 / 괄호 숫자 / 직접 지정. 각 행의 이 파일 남기기로 변경할 수도 있습니다.
6. 남길 파일 제외하고 선택 → 선택한 파일 휴지통으로 이동 → 확인.
7. 실제 파일을 Windows 휴지통으로 이동한 뒤, 성공한 파일에 연결된 다운로드 기록만 지웁니다. 방문 기록은 건드리지 않습니다.
8. 처리 진행률과 이동 성공/실패/남김/기록 정리 실패를 확인하세요. 최근 결과는 앱에서 다시 볼 수 있습니다.

주의할 구분
- 기록만 지우는 기능에서 실제 파일까지 휴지통으로 옮기는 기능으로 변경됐습니다.
- 다운로드 날짜 대신 현재 파일의 수정 날짜를 비교합니다. 숫자가 높다고 내용상 최신 버전이라는 보장은 없습니다.
- 원래 경로에 없거나 보호된 파일의 기록은 남깁니다. 다른 곳으로 옮긴 파일은 추적해서 삭제하지 않습니다.
- 하나뿐인 파일, 동률 묶음, 직접 지정하지 않은 묶음은 자동 삭제 대상으로 선택하지 않습니다.
- 파일 이동은 성공했지만 기록 정리가 실패하면 파일은 휴지통에 있고 기록은 Chrome에 남을 수 있습니다. 결과에서 구분합니다.
- 파일은 휴지통에서 복원할 수 있지만 지운 다운로드 기록은 복원할 수 없습니다.
- 확인 탭은 15분 안에 완료하세요. 도중에 닫으면 일부 작업이 완료됐을 수 있으니 앱의 최근 결과를 확인하세요.

정리 전후 용량 그래프
- 드라이브 단위로 정리 전과 정리 후 도넛을 나란히 보여줍니다.
- 레드: 휴지통을 제외한 사용 공간. 보라: Windows가 보고한 현재 사용자 휴지통 용량. 회색: 운영체제에서 측정한 실제 빈 공간.
- 휴지통 용량 조회 실패 시 측정 불가로 표시하고 사용 공간에 포함합니다. 휴지통이 전체 사용량보다 크게 보고되면 도넛의 해당 영역은 사용량 범위로 제한됩니다.
- 휴지통 수치는 Windows Shell 보고값이며 압축/희소 파일 등에서는 물리 점유량과 차이가 날 수 있습니다. 회색 영역과 빈 공간 증감은 실제 드라이브 측정값입니다.
- 아래 색상별 카드에는 문서/사진/영상/음악/압축파일/기타 중 이동에 성공한 파일의 논리 용량을 표시합니다.
- 휴지통으로 이동했다고 디스크 빈 공간이 바로 늘지는 않습니다. 휴지통을 자동으로 비우지는 않습니다.
- 실제 빈 공간 증감에는 다른 프로그램의 파일 생성/삭제도 반영될 수 있습니다.

파일 정리
폴더 선택 → 같은 이름 / 전체 파일 등의 분류 → 파일 형식 또는 확장자 필터 → 남길 기준 → 정리할 항목 선택 → 휴지통으로 이동.
같은 이름은 기본적으로 같은 폴더·확장자를 기준으로 합니다. 다른 폴더까지 비교하는 옵션은 별도로 켤 수 있습니다.
남길 기준 변경 또는 다시 검사 시 직접 지정과 삭제 선택은 초기화됩니다.
전체 파일 분류는 사용자가 직접 선택하므로 최신 파일 자동 보호를 적용하지 않습니다.
확장자 목록에는 기본 형식을 항상 표시하고, 검사에서 찾은 사용자 확장자도 추가합니다.

폴더 용량
크기순/수정 날짜순 정렬, 뒤로/앞으로/상위 폴더 이동을 지원합니다.
체크박스는 선택, 폴더 열기는 이동입니다. 전체 선택은 다음 80개 보기를 누르기 전 항목도 포함합니다.
폴더를 선택해 정리하면 그 안의 모든 파일이 함께 휴지통으로 이동합니다. 확인 후 실행하세요.
목록 이후 내용이 바뀌거나 연결 경로/보관함을 포함한 폴더는 건너뜁니다.

기존 보관함 복원 및 표시 복구
기존 보관함이 포함된 원래 검사 폴더를 선택하면 보관한 파일을 원래 위치로 복원할 수 있습니다. 새 보관함 이동은 지원하지 않습니다.
Downloads가 영어로 표시되면 왼쪽 아래 다운로드 표시 복구를 누르세요. 표시 설정만 복구하며 실제 폴더명과 경로는 바꾸지 않습니다.
desktop.ini는 개별 정리 후보에서 보호합니다. 직접 선택한 폴더를 통째로 옮기면 그 안의 설정 파일도 함께 이동합니다.

검증
임시 파일을 사용해 같은 이름 묶기, 날짜/숫자/직접 지정, 남길 파일 보호, 검사 후 변경 차단, 폴더 정리와 하위 목록 갱신을 검증했습니다.
로컬 연결 통합 테스트와 Chrome API 모의 테스트로 파일 이동 성공 항목에만 기록 삭제 권한을 발급하는 흐름을 확인했습니다.
그래프 DOM 테스트로 휴지통 증가와 실제 빈 공간 유지, 종류별 이동 용량을 검증했습니다.
실제 Windows 휴지통, 설치된 Chrome 도우미, 고해상도 화면 및 드라이브 용량 측정은 이 환경에서 실행 검증하지 못했습니다.

재배포 시 개인 정보 제외
app/chrome-last-result.json, 크롬 다운로드 연결 도우미/pair.json, app/display-backup 폴더는 사용 후 생성되는 개인 설정/결과입니다. 다른 사람에게 재배포할 때 제외하세요.

[v0.7.13 변경]
파일 정리 행의 파일 열기 버튼은 Windows 연결 프로그램으로 엽니다. 실행 파일(.exe, .bat, .lnk 등)은 실행하지 않고 미리보기를 보여 줍니다. 제작사·버전·디지털 서명, 바로가기의 실행 대상, 스크립트 내용 앞부분을 확인할 수 있어요. 버튼을 눌러도 선택 상태는 바뀌지 않습니다.
확장자 선택 글씨를 중앙 정렬했습니다.
정리 후 불필요한 보관함 재검사와 중복 용량 측정을 줄였고, 결과 준비 중에는 99%와 안내를 표시합니다. 결과 수신 시 100%로 완료합니다.

[v0.7.13 다운로드 표시 복구]
왼쪽 아래 다운로드 표시 복구 → 다운로드 표시 복구를 누르세요. Windows에 등록된 실제 다운로드 폴더를 찾아 기본 이름 리소스와 아이콘, desktop.ini 숨김·시스템 속성과 폴더 읽기 전용 속성을 복원합니다. 기존 설정 파일은 app/display-backup에 백업하고 다른 설정은 보존합니다.
탐색기에서 계속 영어로 보이면 작업 관리자 → Windows 탐색기 → 다시 시작 또는 PC 재부팅을 진행하세요. 실제 Windows 표시 결과는 추가 확인이 필요합니다.

[v0.7.14]
왼쪽 휴지통 비우기에서 용량과 삭제 범위를 확인한 뒤 영구 삭제하기를 누르세요. 현재 사용자의 모든 드라이브 휴지통이 대상이며 기존 휴지통 파일도 포함됩니다. 자동으로 비우지 않습니다.
정리 결과는 1/2 그래프, 2/2 종류별 이동량과 파일 목록으로 나뉩니다. 여러 드라이브는 선택하여 비교하고 파일 목록은 이전/다음으로 넘깁니다. 매우 작은 창이나 높은 확대 배율에서는 스크롤이 생길 수 있습니다.

[v0.7.15 크롬 버전 비교]
파일명 버전 우선: 같은 폴더·확장자에서 v0.7.13처럼 v 뒤에 점으로 구분된 숫자를 비교합니다. 나머지 이름(Windows/x64/Portable 등)이 같아야 한 묶음입니다. 끝의 (1)은 복사본 번호이며 버전이 아닙니다. 최고 버전이 여러 개면 직접 남길 파일을 골라야 합니다. 버전 표기가 없으면 같은 이름 묶음 내에서 수정 날짜로 판단합니다. 베타/RC 등 다른 접미사는 별도 묶음으로 유지합니다. 실제 내용이 최신인지는 보장하지 않으므로 후보를 확인하고 이동하세요. 이미 없는 파일의 기록은 이번 버전도 그대로 남깁니다.

[v0.7.16]
휴지통 비우기를 왼쪽 메뉴의 크롬 다운로드 바로 아래로 옮겼습니다. 다른 메뉴와 같은 크기와 선형 휴지통 아이콘을 사용합니다. 삭제 범위와 영구 삭제 확인 동작은 유지합니다.

[v0.7.17]
정리 결과 2/2의 표를 카드 너비에 맞췄습니다. 긴 이름·경로·날짜는 줄바꿈하고 글씨 크기를 조정하여 가로 스크롤을 없앴습니다. 세로 스크롤과 파일 목록 이전/다음은 유지합니다.

[v0.7.18 크롬 다운로드]
남김 추천 파일도 체크박스 또는 행 클릭으로 선택하여 휴지통으로 이동할 수 있습니다. 추천 파일까지 선택하면 실행 확인 창에 개수가 표시됩니다. 정리 후보만 선택은 추천·동률 파일을 자동 선택하지 않습니다.
기준은 높은 버전 남기기 / 최근 수정한 파일 남기기 / 큰 복사본 번호 남기기로 표시하고 예시 설명을 제공합니다. 직접 지정 옵션은 제거했습니다. 선택한 파일만 이동하며 한 묶음 전체를 직접 선택할 수도 있습니다. 시스템 보호·변경 감지 검사는 유지합니다.
