1. 시작하기
① ZIP을 새 폴더에 전체 압축 해제하세요. ZIP 안에서 바로 실행하지 마세요.
② 쓱-싹.exe를 실행하세요. Google Chrome이 설치되어 있어야 합니다.
③ 먼저 ‘파일 구조화 → 가상 테스트 실행’으로 연습해 보세요.
실제 문서 대신 별도 임시 폴더에 샘플이 생깁니다. 테스트 폴더는 확인 후 직접 삭제할 수 있어요.

중요: 폴더 안의 app과 연결 도우미는 프로그램 구성 요소입니다.
실행 파일만 따로 옮기지 말고 압축을 푼 폴더 전체를 함께 보관하세요.
처음에는 중요한 파일을 백업하고 작은 테스트 폴더부터 정리하세요.

2. 어떤 메뉴를 쓰나요?
• 파일 정리: 선택한 폴더를 검사하고 정리할 파일을 직접 선택합니다.
  ‘같은 이름’ 분류에서 비슷한 이름/공통 단어 묶기와 남길 기준을 고를 수 있어요.
• 정크 파일: 오래된 임시 파일과 확인 가능한 캐시를 살펴봅니다.
• 폴더 용량: 큰 폴더와 파일을 찾아봅니다. 표시된 정렬 기준을 확인하세요.
• 이전 버전 보관함 복원: 옛 버전의 별도 보관함 파일만 복원합니다.
  현재 앱이 휴지통으로 옮긴 파일은 Windows 휴지통에서 복원하세요.
• 크롬 다운로드: 다운로드 기록에 연결된 실제 파일을 비교합니다.
  아래 ‘크롬 연결’ 설정이 필요합니다. 압축 해제한 폴더는 이 화면의 대상이 아닙니다.
• 파일 구조화: 폴더 생성, 이름 변경, 이동, 텍스트 수정본 저장,
  99_아카이브 보관, 앱 내부 즐겨찾기를 이용합니다. 회색 예시는 입력하면 사라져요.

3. 크롬 다운로드 연결 — 처음 한 번만
‘크롬 다운로드 연결 도우미’는 무엇인가요?
쓱-싹이 사용하는 크롬 프로필의 다운로드 목록을 읽고, 이동에 성공한 파일의
다운로드 기록을 정리할 수 있도록 연결하는 크롬 확장 프로그램입니다.
일반 ‘파일 정리’만 쓸 때는 등록하지 않아도 됩니다.

① 앱의 ‘크롬 다운로드 → 크롬 연결 도우미 등록하기’를 누르세요.
② 열린 크롬 확장 프로그램 화면에서 ‘개발자 모드’를 켜세요.
③ ‘압축해제된 확장 프로그램을 로드합니다’를 누르세요.
④ 이 README와 같은 위치에 있는 ‘크롬 다운로드 연결 도우미’ 폴더를 선택하세요.
   ZIP, app, 또는 쓱-싹 전체 폴더가 아니라 이 도우미 폴더 자체를 선택합니다.
⑤ 앱으로 돌아와 ‘다운로드 파일 확인’을 누르세요.

기존 연결 도우미를 등록했다면: 예전 확장을 제거하고 위 새 폴더를 등록하세요.
쓸 크롬 프로필마다 등록이 필요합니다. 등록 후 도우미 폴더를 옮기거나 삭제하면
연결이 끊길 수 있어요. 위치를 바꿨다면 새 위치의 폴더를 다시 등록하세요.

4. 안전하게 정리하는 순서
① 검사 → ② 묶음/남김 추천 확인 → ③ 정리할 항목 선택 → ④ 휴지통 이동
‘전체 선택’은 정리 대상을 꼭 확인한 뒤 사용하세요.
크롬 화면에서는 남김 추천 파일도 직접 체크하면 함께 이동할 수 있으니 주의하세요.
비슷한 이름이나 공통 단어는 내용이 같다는 뜻이 아닙니다.
높은 버전은 v1.2 같은 숫자를 비교하고, 수정 날짜는 다운로드 날짜와 다릅니다.
날짜가 최신이라고 실제 내용까지 최신이라고 보장할 수는 없어요.

공통 단어 묶기
• 자동: 의미 있는 단어가 2개 이상 겹치는 파일을 후보로 묶어요.
• 직접 입력: 입력한 연속 문구를 포함한 파일을 묶어요. 예: Sseuk-Ssak
• 같은 폴더·확장자·표기된 플랫폼 안에서 비교합니다.
• 묶기만으로 이름이 바뀌거나 파일이 삭제되지는 않습니다.

5. 화면과 용량 안내
• 창을 줄이면 내부 요소도 함께 축소됩니다. 가로 스크롤 없이 창 너비에 맞춰 계속 축소합니다. 작은 창에서는 글씨도 작아져요.
• 전체 용량은 청록색, 사용 중은 빨강, 휴지통은 보라, 빈 공간은 회색입니다.
• 휴지통 비율이 작으면 보라색이 거의 안 보일 수 있어요. 옆 수치를 확인하세요.
• 휴지통으로 옮겨도 실제 빈 공간은 바로 늘지 않습니다.
• ‘용량 다시 측정’은 현재 용량을 갱신하고 이전 전후 비교는 초기화합니다.

6. 자주 막히는 부분
• 실행 경고: 코드 서명이 없는 배포본이라 Windows 경고가 나타날 수 있습니다.
  신뢰할 수 있는 출처인지 확인하고, 보안 기능 전체를 끄지는 마세요.
• 도우미 연결 실패: 같은 크롬 프로필인지, 새 도우미가 등록/활성화됐는지 확인하세요.
• 목록에 없음: 파일이 원래 위치에 있는지 확인하세요. 크롬 정리는 다운로드 기록 대상입니다.
• 복원이 안 보임: Windows 휴지통, 이전 버전 보관함, 99_아카이브는 서로 다릅니다.
• 새 문서/수정본: txt/md/csv만 지원해요. PDF/Word 편집기는 아닙니다.

확인 범위
이 배포본은 자동 테스트 28개 및 코드/ZIP 검증을 거쳤습니다.
Windows 실제 화면과 실행 확인 및 코드 서명은 수행하지 못했습니다.


폴더 비교 기능 (Update10)
파일 정리에서 비교 대상 폴더들이 들어 있는 상위 폴더를 선택하고 검사하세요.
왼쪽 ‘폴더 정리’ 메뉴에서 위치를 선택하고 ‘비슷한 폴더 찾기’를 누릅니다.
선택한 폴더 바로 아래의 폴더만 찾으며, 이름에서 명시적인 v1.2 버전과 끝의 (1) 같은 복사본 번호를 제외해 비교합니다.
예: App-v1.0 / App-v1.1. 임의의 공통 단어 폴더 묶기는 아직 지원하지 않습니다.
정리할 후보 폴더와 남길 기준 폴더를 직접 선택하고 ‘내용 비교’를 누르세요.
내부의 상대 경로 및 파일 SHA-256 해시로 동일/후보에만/기준에만/내용 다름을 구분합니다.
후보에만 있는 빈 폴더도 표시합니다. 파일 메타데이터·권한·대체 데이터 스트림 등은 동일성 비교 대상이 아닙니다.
차이가 있으면 별도 확인 체크가 필요합니다. 자동 삭제하지 않고 선택한 후보 폴더 전체만 휴지통으로 이동합니다.
이동 직전 두 폴더의 변경 여부를 재검사합니다. 검사 중에는 파일을 다른 앱에서 수정하지 마세요.
대용량 폴더는 내용을 읽어 비교하므로 시간이 걸릴 수 있습니다. 앱·보관함·연결 경로 등 보호된 항목은 제외하거나 작업을 거절합니다.
복원은 Windows 휴지통에서 할 수 있습니다. 먼저 테스트 폴더로 연습하고 중요한 파일은 백업하세요.
자동 테스트 총 34개 통과. Windows 실제 실행/화면 검증은 수행하지 못했습니다.

첫 파일 정리 화면은 폴더 선택 버튼만 크게 보여줍니다. 폴더를 선택하고 검사하면 필터와 결과 목록이 나타납니다.


다시 검사 / 선택 초기화 (Update13)
파일 정리에서 폴더를 선택한 뒤 화면 위쪽에 표시됩니다.
다시 검사: 현재 폴더를 다시 검사합니다.
선택 초기화: 확인 후 현재 폴더/검사 결과/묶기 설정을 비우고 처음 화면으로 돌아갑니다.
실제 파일을 삭제하지 않으며 이전에 옮긴 파일을 되돌리는 기능이 아닙니다.
다른 메뉴와 공유하는 검사 폴더 및 검사 결과도 초기화됩니다. 스마트 정리의 별도 관리 폴더는 유지됩니다.

폴더 사이 같은 이름 파일 비교
비교할 폴더들이 들어 있는 공통 상위 폴더를 선택해 검사합니다.
파일 정리 → 같은 이름 → 기본 이름 → 하위 폴더 사이의 같은 이름 파일 비교를 켭니다.
현재 검사 위치와 그 하위 폴더를 재검사해 같은 이름 파일을 비교합니다.
예: 상위/A/보고서.txt 와 상위/B/보고서.txt.
공통 단어 묶기는 폴더별 비교이므로 이 작업에서는 끄세요.
이름이 같다고 내용이 동일한 것은 아닙니다. 남길 파일을 확인하고 나머지를 선택하세요.
공통 상위 폴더 밖의 임의 경로 여러 개를 동시에 선택하는 기능은 아닙니다.
